# MemoryPalace

**SHERLOCK:** _Get out. I need to go to my mind palace.

**MOLLY:** _His what?

**JOHN:** _His mind palace. It’s a memory technique, a sort of a mental map. You plot a map with a location—it doesn’t have to be a real place—and then you deposit memories there. Theoretically, you can never forget anything. All you have to do is find your way back to it.

**MOLLY:** _So Sherlock’s got a palace? Is it big?_

**JOHN:** _He’s Sherlock. What do you think?_

Taking inspiration from the Sherlock Holmes mind palace (memory palace, Method of Loci), spaced repetition techniques and the backlog of reading notes I've compiled.

This tool can be installed and used as a local method of note compilation.  The method I used and created this tool for is feeding in my notes in text, pdf, document format and it extracting the text to a local SQL database.  This will then give the documents in bitesize chunks for reading and digesting.  From here you are automatically in a spaced repetition system and can choose to mark the card as known (the card is reviewed on the next scheduled interval, deleted (completely removed with not backup retrieval), or mark the card as unknown where it will go the the bottom of the pile for review again for review.
The downside to this is that when digesting for the first time the data won't be reviewed for some time.  The theory being that initially you read the books and take in a first glance of the information.  Then each time you work through and review you are removing and editing the cards to summarise in your own works and notes.  Each review should reduce the volume to just the essentials.
